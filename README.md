# Laravel UX

Laravel UX is a suite of full-stack components crafted to streamline [Laravel](https://laravel.com/) development, offering seamless integration with [Livewire](https://livewire.laravel.com/) interfaces and leveraging [shadcn/ui](https://ui.shadcn.com/) for a modern, [Tailwind CSS](https://tailwindcss.com/) - powered design.

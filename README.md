# Laravel UX UI

Laravel UX UI is a component system for Blade and Livewire based on [shadcn/ui](https://ui.shadcn.com/). It provides
accessible, composable primitives with Tailwind CSS styling, forwarded Blade attributes, and consistent patterns
for forms, navigation, overlays, feedback, and data display.

The package includes guidance for Laravel Boost and supported AI coding agents, helping them select, compose, and
customize components using the same conventions as the package.
